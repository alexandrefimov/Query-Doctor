# Community Starter Issues

Last reviewed: 2026-05-15

Язык: [English](../../community-starter-issues.md) | Русский

Английская версия является канонической. Эта страница кратко объясняет backlog
для публичных starter issues.

## Назначение

Starter issues должны быть безопасными для внешних contributors:

- без raw production SQL, profiles, metadata или credentials;
- без local paths, hostnames, users, emails, command output или model/runtime
  internals;
- с понятным scope и expected validation.

## Как использовать

Перед публикацией issue проверьте, что пример synthetic или sanitized. Для
полного списка candidates используйте
[английский backlog](../../community-starter-issues.md).
