# Заметки к релизу 0.3.0

Last reviewed: 2026-05-26

Язык: [English](../../release-notes-0.3.0.md) | Русский

Английская версия является канонической. Эта страница - краткое русское
резюме опубликованного релиза `0.3.0`.

## Релиз

`0.3.0` опубликован 2026-05-23. Текущий реализованный движок остается Impala.
Поддержка других движков не заявляется.

## Основные изменения

- Recent Scan и Details стали основным пользовательским путем.
- Workload triage получил более полезное ранжирование подозрительных случаев.
- Query Optimizer остался read-only workflow с защитой от выполнения SQL.
- Analyzer стал строже отделять поддержанные, не обнаруженные и неизвестные
  сигналы.
- Публичный пакет и репозиторий получили Apache-2.0 baseline.
- Конфигурация, локальные проверки и документация были подготовлены для
  публичного использования.
- Заложены исследовательские основания для будущих движков без заявления
  текущей поддержки.

## Ограничение

Релиз не делает Query Doctor универсальным multi-engine продуктом и не
добавляет автоматическое выполнение SQL. Все доверенные выводы по-прежнему
должны идти от детерминированных фактов analyzer.
