# Demo Data Engineer Brief

Last reviewed: 2026-05-28

Язык: [English](../../demo-data-engineer-brief.md) | Русский

Английская версия является канонической. Эта companion-страница кратко
пересказывает brief для data engineer demo.

Страница актуальна как methodology/scoring brief, но не должна ссылаться на
старые prepared-pack case IDs, account names, query IDs или local deep links.
Для публичного demo используйте synthetic pack из `query-doctor-demo`.

## Цель brief

Документ помогает провести demo через persona data engineer:

- открыть synthetic Recent scan;
- начать с Workloads / Action Queue, чтобы показать immediate value;
- выбрать подозрительный case;
- прочитать deterministic facts;
- запустить explicit trusted report action;
- показать, что Query Doctor не является chat wrapper и не показывает raw SQL.

## Safety

Brief не должен включать production SQL, real profiles, hostnames,
credentials, local paths, account names, query IDs или raw generated artifacts.

Полный сценарий: [английский brief](../../demo-data-engineer-brief.md).
